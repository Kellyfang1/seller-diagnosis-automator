# Direct-send Seller Message Template

`XX，我和[经理名称]一起看了下店铺。`

`先说结论，[本期成交/转化/核心款表现]，说明现有货盘里已经有能卖的款。当前更影响结果的是[可验证的根因：货盘重复、属性/标题不完整、价格带、图片或库存]，买家在搜索、筛选或下单时会遇到[具体问题]。`

`首轮请优先完成表内[数量]款：`

1. `聚焦[产品方向]，减少[重复或低效方向]；同款的颜色和尺码合并到同一链接。`
2. `按表内西语标题更新，并补齐性别、品类、材质、尺码、真实功能和使用场景；没有的功能不要写。`
3. `首图使用清晰人模或产品图，后续补齐[背面/材质/功能/尺码表]。`
4. `按表内建议价做[7-14]天测试；请先填写最低可售价，确保不低于成本和利润底线。`

`完成后回传标题、属性、图片、变体、价格和库存，我会先做页面检查。页面和库存通过后，再安排后续测试。单款累计约[阈值]次访问仍没有订单，就先暂停并换图、改价或换款。`
